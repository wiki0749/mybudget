# mybudget
* single page HTML 5 app 
## features
* enter regular and irregular income
* balance tracking
* prediction of future balances
* table view
* graph view

## Design 
* colors : white, pink, dark pink, light pink, light purple
* responsive design 

## Suggestions
* categorize income and expenses to make spending patterns easier to understand
* set monthly budgets and show a warning when a budget is close to being exceeded
* create savings goals and track progress toward each goal
* save data in the browser so it is still available after closing the app
* add an option to export and import data as a CSV file
* include a date range filter for the table and graphs
* make the app accessible with keyboard navigation, readable contrast, and clear labels
